## 优惠码填了没反应，按这个顺序查

先确认套餐和付款周期在不在适用范围内。这是最常见的原因，尤其是“仅限年付”“仅限新购”“仅限指定套餐”这三类限制。666Clouds 这边对应的就是德国优化线路年付特价和特价专区，填了不打折是规则如此。HostDare 的洛杉矶 Cheap 系列也是同一类情况：折扣只在前 3 个付款周期有效，之后按原价续费，CN2-GIA NVMe 系列压根不适用，而且实测只有年付、两年付、三年付能打折，月付季付半年付填码没反应。

第二步看填的位置对不对。优惠码要填在结账页的 Promo Code 输入框里，购物车页面没有这个框。有些站的流程是先加购物车再进结账，中间隔了一页，很多人卡在购物车那页找不到输入框就以为码废了。

第三步，确认价格真的变了再付款。填完码页面会重新计算，实付金额、首付和续费条件都在那一步显示。看不到金额变化就别点提交。

第四步，部分码是限量的，名额用完或者提前结束都很正常，最终以厂商结账页显示为准。做优惠汇总的站点一般会把过期的码从列表里下线，但下线有时间差，看到“长期有效”也别当成永久有效。

还有个反常识的点：缺货的套餐也能用码。补货的那一刻点进购买页，结账时粘贴优惠码，照样生效，不用等有货了再去找码。

循环优惠和首期优惠的区别，值得单独说一句。循环折扣（Recurring）在续费时同样打折，长期用更划算；首期或前几期优惠只对首次或前几次账单有效，之后按原价走。前面那笔账已经算过，JustHost 一年下来两者差 139 元。选码之前先问自己一句：这台机器我打算用多久？三个月以内选首期，超过半年选循环。
